# MY AI STUDY PLANNER

A simple, beginner-friendly Python project that creates a personalized weekly study plan for someone learning about Artificial Intelligence (AI).

## Features

- Asks for the student's name
- Asks for the student's AI learning goal
- Collects study days per week and daily study hours
- Calculates total weekly study hours
- Displays a personalized study plan
- Saves the plan to `study_plan.txt`
- Uses only basic Python—no external packages, AI API, GUI, or database

## Requirements

- Python 3.8 or newer (Python 3 is recommended)

## How to run

1. Download or clone this repository.
2. Open a terminal or command prompt in the project folder.
3. Run:

   ```bash
   python study_planner.py
   ```

   On some systems, use:

   ```bash
   python3 study_planner.py
   ```

4. Answer the questions shown in the terminal.
5. Your personalized plan will be displayed and saved in `study_plan.txt`.

## Example

If you study 3 days per week for 2 hours each day:

`Total weekly study hours = 3 × 2 = 6 hours`

The program creates a plan with three study sessions and suggests a simple activity for each session.
